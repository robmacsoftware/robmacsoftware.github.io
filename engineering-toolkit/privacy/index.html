1. Introduction

Engineering Toolkit is an engineering utility application developed by RobMac Software.

We respect user privacy and aim to provide practical engineering tools without unnecessary collection of personal information.

This Privacy Policy explains how Engineering Toolkit processes, stores, and handles information when users interact with the application.

2. Data Collection and Sharing

Engineering Toolkit operates offline and does not require users to create an account.

The application does not automatically collect or transmit user information to RobMac Software or external servers.

Engineering Toolkit does not incorporate advertising services, analytics platforms, crash-reporting services, or cloud synchronization.

Calculator inputs and results are processed locally on the user's device.

The application does not automatically transmit calculation data to RobMac Software or third-party analytics or advertising services.

Certain user-initiated actions, such as copying a result to the clipboard, may make information available to the operating system or other applications, as explained below.

3. Local Data Storage

Engineering Toolkit stores limited information locally on the user's device to support application functionality and preferences.

This information includes:

  • Appearance and theme preferences.
  • Identifiers of favorite calculators.
  • Identifiers of recently used calculators.

Calculator inputs, calculation results, substitutions, searches, and other temporary calculation information are processed in application memory during the relevant session.

This calculation information is not persistently stored as part of the application's local preferences.

RobMac Software does not operate a remote database containing user calculations or application preferences.

4. Clipboard Functionality

Engineering Toolkit allows users to copy calculation results to the device clipboard.

This operation occurs only when the user explicitly selects the Copy result action.

Copied information may include the calculator name, result name or symbol, calculated value, unit when applicable, and calculation substitution.

The substitution may contain values entered by the user.

Once copied, this information is managed by the device's operating system.

Depending on the Android version, device manufacturer, keyboard application, and configured services, clipboard content may be retained, accessed, or synchronized outside Engineering Toolkit.

RobMac Software does not control how the operating system or other applications subsequently manage clipboard content.

5. Android Backup and Data Transfer

Engineering Toolkit is configured to disable Android's automatic application backup and exclude application data from supported standard cloud-backup and device-to-device transfer mechanisms.

These restrictions are implemented through Android's application backup settings and data extraction rules.

However, backup and transfer behavior may vary depending on the Android version, device manufacturer, and system services.

Certain manufacturer-specific or privileged transfer mechanisms may operate outside the application's configurable restrictions.

Previously created system-managed backups may also remain available according to the operating system or backup provider's policies.

RobMac Software does not provide its own cloud backup, remote restoration, or data synchronization service for Engineering Toolkit.

6. Data Retention and Deletion

Engineering Toolkit stores application preferences locally to preserve the user's selected appearance, favorite calculators, and recently used calculators.

These preferences remain available until the application's local data is cleared or the application is uninstalled, subject to the operating system's backup and restoration behavior.

Users can remove locally stored application information through their device's Android application settings by clearing Engineering Toolkit's application data.

Uninstalling the application also removes its locally stored data from the current installation under normal Android behavior.

Calculator inputs and results are maintained only during the relevant application session and are not stored as persistent calculation records.

Clearing application data or uninstalling the application does not necessarily delete backups previously created or retained by operating-system services.

Engineering Toolkit does not maintain user accounts or remotely stored calculation histories.

7. Data Security

Engineering Toolkit is designed to process calculations locally without transmitting calculation information to external servers.

Locally stored application data relies on the application storage protections and security mechanisms provided by Android and the user's device.

The effectiveness of these protections may depend on the device configuration, operating system, and security settings.

Engineering Toolkit does not require users to provide personal account credentials.

8. Changes to This Privacy Policy

RobMac Software may update this Privacy Policy to reflect changes to Engineering Toolkit, its functionality, or its information-handling practices.

Any updates will be published on this page, together with the corresponding revision date.
